# Security Policy

## Supported versions

Only the latest published version is supported.

## Reporting a vulnerability

Please do not disclose security issues in a public issue first. Report a vulnerability through the repository's private security advisory workflow, including a clear description, impact, reproduction steps, and a suggested mitigation when available.

SSH Orbit is an administrative tool. Run it with a dedicated least-privilege account, configure `SSH_ORBIT_ALLOWED_TARGETS`, and enable strict host-key verification with `known_hosts` or fingerprints for production use.
